Claude 账号切换 v1.1.0
======================

在同一台 Windows 电脑上，给 Claude Code（VS Code 插件或命令行）切换多个 Claude 账号，
并查看每个账号的 5 小时额度、本周额度和重置时间。不用每次重新登录、收验证邮件。


一、开始使用
------------
1. 把 ClaudeSwitch.exe 放到一个固定的位置（比如 D:\工具\），然后双击打开。
   第一次打开会在桌面建一个「切换Claude账号」快捷方式，以后双击它就行。
   （之后如果移动了 exe，请删掉旧快捷方式，自己重新建一个。）
2. 打开时，Claude 插件当前登录的账号会自动保存进来。

如果 Windows 弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
这是因为个人打包的程序没有数字签名，不是病毒。


二、添加其他账号（每个账号只做一次）
------------------------------------
1. 在 VS Code 的 Claude 插件输入框里打 /，选登录（/login），用另一个账号登录。
2. 回到「Claude 账号切换」窗口，点右上角「刷新」，新账号就出现了。

注意：用 /login 直接换账号，不要先 /logout，退出登录可能让之前保存的账号失效。


三、切换账号
------------
1. 在窗口里点「切换到这个账号」。
2. 回到 VS Code，按 Ctrl+Shift+P，输入 Reload Window 回车。重新加载后就是新账号。
   开了几个 VS Code 窗口，就每个都要 Reload 一次（或者直接重启 VS Code）。
   最好等手头的对话结束再切换。


四、窗口里的信息
----------------
- 本工具完全本地：不联网查询，只读你电脑上 Claude 插件留下的数据，也从不刷新令牌。
- 5 小时 / 本周：额度已用的百分比（绿色 < 60%，橙色 < 85%，红色 ≥ 85%）和重置时间。
  每个账号下面写着这是什么时候的数据：
    · 正在用的账号：来自 Claude 插件。想看最新的，在插件里输入 /usage，再点「刷新」。
    · 其他账号：上次使用这个账号时的数据。过了重置时间就不再显示旧的百分比，
      改为「已重置」，切换到这个账号后可查看最新余量。
    · 暂无用量：切换到这个账号，在插件里输入 /usage 后点「刷新」，以后就有了。
- 「剩余额度最多」：按上面的数据，自动标出现在最宽裕的账号。
- 登录还剩 N 天：登录大约 4 周有效，到期前在插件里 /login 那个账号一次，再点「刷新」。
  剩不到 3 天会变色提醒。
- 令牌 xx:xx 到期：短期令牌约 8 小时，由插件自动续期（没在用的账号切换过去后续期）。
- 「刷新」：重新读取本机数据。标题下面显示上次刷新的时间。
- 窗口可以上下拉伸：最矮显示 2 个账号，最高显示 3 个账号，放不下的账号用右边的滚动条
  （鼠标滚轮或拖动）查看。
- 同时只能开一个窗口：已经开着时再双击，会把原来的窗口调到最前面。


五、设置（右下角「⚙ 设置」）
----------------------------
- 常规：切换界面语言（中文 / 日本語），点一下立即生效，下次打开也会记住。
- 关于：版本号。点「检查更新」看有没有新版本；有的话点「打开下载页」，
  下载新的压缩包，关掉本工具后用新的 ClaudeSwitch.exe 替换旧的即可，账号数据不受影响。


六、会生成哪些文件
------------------
- %USERPROFILE%\.claude-accounts\profiles\<邮箱>.json   每个账号一个，里面是登录令牌
- %USERPROFILE%\.claude-accounts\claude.json.bak         切换前的配置备份
- %USERPROFILE%\.claude-accounts\usage-cache.json        各账号上次使用时的用量
- %USERPROFILE%\.claude-accounts\settings.json           设置（界面语言）
- 桌面「切换Claude账号」快捷方式（只在第一次运行时建）
切换时只改 %USERPROFILE%\.claude\.credentials.json 和 %USERPROFILE%\.claude.json
里的登录部分，其他设置不动。不写注册表、不开机自启。

完全删除：删掉 exe、桌面快捷方式和 %USERPROFILE%\.claude-accounts 文件夹即可。


七、注意
--------
- .claude-accounts 文件夹里有你的登录令牌，千万不要发给别人或上传到网上。
- 每个人只保存自己的账号，账号共用违反 Anthropic 的使用条款。
- 读的是 Claude 插件的本地文件，插件大版本更新后可能需要更新本工具。
- 唯一会联网的是「设置 → 关于 → 检查更新」，而且只在你点按钮时查 Gitee。
- 切换后，每个开着 Claude 的 VS Code 窗口都要 Reload Window（或重启 VS Code）。
  否则旧会话还拿着上一个账号的令牌，可能出现「OAuth session expired」要求重新登录。
- 只支持 Windows。
